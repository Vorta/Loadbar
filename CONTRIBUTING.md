# Contributing to Loadbar

Thanks for helping improve Loadbar. This is a native Windows project with no third-party
runtime dependencies. Read [AGENTS.md](AGENTS.md) for the project contract and
[docs/architecture.md](docs/architecture.md) for component boundaries.

## Report a problem

Search existing issues before opening one. Include the Loadbar version, Windows build,
monitor orientation and DPI, the selected edge/thickness, steps to reproduce, expected
behavior and actual behavior. A cropped screenshot can help. Remove serial numbers,
network identifiers, unrelated windows and other private information.

For incorrect readings, identify the metric and its raw status from Settings, plus the
comparison tool's source/interval/device scope. A Task Manager aggregate alone cannot
validate a per-logical-processor measurement. Do not generate load or alter machine-wide
settings merely to collect a bug report.

## Make a change

1. Fork the repository and create a focused branch.
2. Use the pinned tools and build/test commands in [README.md](README.md).
3. Add regression coverage for fixes. Keep normal tests independent of real hardware and
   desktop changes; interactive checks are opt-in and recorded separately.
4. Run formatting, clang-tidy and MSVC analysis. Use Release for validation and ASan when
   changing memory/resource ownership. Never weaken diagnostics to pass a check.
5. Describe the user-visible change, relevant tests and remaining verification limits in
   the pull request. Update the appropriate docs when behavior or procedures change.

There is no configured public GitHub Actions runner for the exact pinned Windows toolchain
yet. Local validation evidence is required; a README badge must not imply unrun CI.
Do not commit out/, binaries, dumps, logs, credentials, local presets or hardware inventories.
The explicitly labeled README media is generated by the optional documentation fixture.
