# Loadbar 1.1.3

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

This update improves vertical layouts and CPU sizing, adds interaction preferences, and
supports shared GPU memory when dedicated-memory readings are unavailable.

## Changes

- **GPU memory fallback.** Prefer valid dedicated-memory readings, then verified adapter-wide
  shared-memory usage. Label the selected scope and retain its last valid observation through
  failures. Until either source has been observed, show only 3D and video decode in a 2:1 split.
- **CPU square option.** Enable **Display CPU usage always as squares** to use square P/E
  tiles. The grid fits the strip thickness and determines the CPU area's length; remaining
  device widgets share the available space. Uniform and unknown CPU classes also fit their
  occupied grid, including high-thread-count layouts. Every logical processor retains its tile.
- **Vertical layouts.** Meters fill upward with upright icons below. Hover text reads top-down
  on Right and bottom-up on Left. E cores sit left of P cores on Right, and right of P cores
  on Left. Native tooltips and Settings text stay upright.
- **Interaction preferences.** **Show info on hover** and **Open Task Manager on click** are
  checked by default. Uncheck either to disable that behavior. Settings migrate automatically;
  presentation changes do not restart telemetry collection.

## Downloads and upgrade

- `Loadbar.exe`: Windows x64 executable.
- `Loadbar-1.1.3-windows-x64.zip`: the same executable, compressed.
- `SHA256SUMS.txt`: checksums for both downloads.

Exit the running version through its tray/bar menu or Settings, replace `Loadbar.exe`,
and launch the new executable. Existing settings remain under `HKCU\Software\Loadbar`.
No installer, service or launch-at-sign-in registration is added.

## Validation status

The implementation passed Debug, Release, RelWithDebInfo and ASan builds and all four
CTest suites, formatting, clang-tidy and MSVC analysis. Production-renderer offscreen tests
cover edge switches, square fitting, text direction, high contrast and resource recovery.
Adversarial reviews led to fixes and clean follow-up reviews. The owner reports that the
updated application looks and works correctly in their manual use.

Release imports contain only Windows components, with no VC++ runtime DLL dependency.
The ZIP contains only the tested executable. Code-level performance review found no
additional actionable regression; it is not a measurement of production CPU, RAM or GPU use.

The full interactive Shell/fullscreen/multi-monitor matrix, hardware accuracy and hotplug,
controlled performance measurements, one-hour soak and clean-machine standalone packaging
remain pending. Publication is explicitly requested with those limitations disclosed;
it does not establish that the remaining release gates passed.
