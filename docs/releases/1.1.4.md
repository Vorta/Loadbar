# Loadbar 1.1.4

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

This update improves the Settings window.

## Changes

- Preference checkboxes now match the surrounding window background.
- **Close** dismisses Settings and discards unapplied changes while monitoring continues.
- **Exit Loadbar** sits on the left and keeps its full label. Apply, Cancel, conditional Retry
  and Close stay on the right, wrapping when needed. Keyboard navigation follows their order.

## Downloads and upgrade

- `Loadbar.exe`: Windows x64 executable.
- `Loadbar-1.1.4-windows-x64.zip`: the same executable, compressed.
- `SHA256SUMS.txt`: checksums for both downloads.

Exit the running version using **Exit Loadbar** or its tray/bar menu, replace `Loadbar.exe`,
and launch the new executable. Existing settings are preserved. No installer is required.

## Validation status

Debug, Release, RelWithDebInfo and ASan builds passed all four CTest suites each. Formatting,
clang-tidy and MSVC analysis passed. Hidden native-window tests cover checkbox background
pixels, footer sizing, keyboard order, draft cancellation and Close without application exit.
Independent adversarial and code-level performance reviews found no actionable issues.
The release imports only Windows components, and the ZIP contains only the tested executable.

The performance review did not measure production CPU, RAM or GPU usage. Live Settings
appearance across Windows themes/DPI, the full Shell/fullscreen/multi-monitor matrix,
hardware accuracy, controlled performance measurements, one-hour soak and clean-machine
standalone execution remain pending. Publication does not establish that these gates passed.
