# Loadbar 1.1.0

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

This update adds control over which device widgets appear and improves the CPU layout
on processors without different core types.

## Changes

- **Hide GPU and Network independently** in Settings. Remaining widgets expand to fill
  the available space. Hidden providers pause while retaining their device preferences,
  last readings and session peaks.
- **Choose which physical drives to show** using the new Drives checkboxes below Network.
  Apply commits changes; Cancel restores them. Hidden choices survive reconnects and restarts,
  while newly discovered drives are shown automatically. The checklist supports keyboard
  navigation and scrolling for longer lists.
- **Equally sized square CPU cores** for processors without distinct efficiency classes.
  Cores sit side by side and wrap when needed. Hybrid P/E-core layouts remain unchanged.
- **Pause hidden drive updates.** Visible drives keep their shared counters; hiding all
  drives closes both disk queries. Showing a drive again primes those queries and preserves
  its session peaks. Device discovery continues while widgets are hidden.

Existing settings migrate automatically, with all device widgets visible by default.
Visibility changes redistribute space in both horizontal and vertical layouts.

## Downloads and upgrade

- `Loadbar.exe`: Windows x64 executable.
- `Loadbar-1.1.0-windows-x64.zip`: the same executable, compressed.
- `SHA256SUMS.txt`: checksums for both downloads.

Exit the running version through its tray/bar menu or Settings, replace `Loadbar.exe`,
and launch the new executable. Settings remain under `HKCU\Software\Loadbar`.
No installer, service or launch-at-sign-in registration is added.

## Validation status

Debug, Release, RelWithDebInfo and ASan builds passed all four CTest suites. Formatting,
clang-tidy and MSVC analysis passed. Two independent consecutive adversarial reviews were
clean after fixes. Release imports contain only Windows components, with no VC++ runtime
DLL dependency. The packaged ZIP contains only the tested executable.

Live Shell/fullscreen/multi-monitor behavior, physical-hardware accuracy and hotplug,
sustained performance/soak, and clean-machine standalone packaging remain pending.
Automated checks and source reviews do not establish those results. See
[testing](https://github.com/Vorta/Loadbar/blob/v1.1.0/docs/testing.md),
