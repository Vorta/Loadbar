# Loadbar 1.2.0

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

This version adds component temperatures, bundled Geist Mono, and a control that stops
temperature collection entirely when it is not wanted.

## Changes

- **Component temperatures.** CPU temperature on compatible ASUS firmware, selected-GPU
  temperature through Windows graphics APIs or installed NVIDIA/AMD/Intel drivers, and
  physical-drive device/composite temperature through Windows storage APIs. Values appear
  below icons after a valid observation, upright on every edge. CPU access outside the
  compatible ASUS interface and RAM temperature remain outside the standalone provider coverage.
- **Show temperatures.** Enabled by default for new and existing installations. Unchecking
  it and selecting Apply hides temperature values and effects and stops new sensor requests.
  Other metrics continue normally. Last-valid temperatures retain their original age when
  collection resumes.
- **Thermal styling.** Icons retain their own colors through 60°C, blend toward the temperature
  text color up to 90°C, then gain a static glow reaching full intensity at 95°C. High contrast
  retains system colors. Geist Mono and its license are embedded in the executable.
- **Reduced unnecessary work.** Confirmed missing vendor capabilities no longer repeatedly
  initialize driver libraries at the normal failure cadence. Hover transitions reuse
  temperature text layouts. Hidden or disabled drives release completed temperature buffers.

## Upgrade

Exit through **Exit Loadbar** or the tray/bar menu, replace `Loadbar.exe`, and launch it.
Settings migrate automatically. No installer, service, elevation or bundled vendor DLL is required.

## Validation status

Debug, Release, RelWithDebInfo and ASan passed all four CTest suites each. Formatting,
clang-tidy and MSVC analysis passed. The release ZIP contains only the tested executable;
imports are Windows components, with optional temperature libraries loaded from installed
drivers. Exact build, regression and independent-review results are in
[testing](https://github.com/Vorta/Loadbar/blob/v1.2.0/docs/testing.md).
After correcting a coalesced temperature-toggle reset, two independent consecutive
adversarial/performance review passes reported no actionable findings.

The owner reported successful manual use and requested publication after the remaining
validation gaps were disclosed. This does not establish completion of the formal release gates.
Controlled 1-Hz performance measurements, the one-hour soak, the full interactive Windows
matrix and clean-machine standalone execution remain pending.
