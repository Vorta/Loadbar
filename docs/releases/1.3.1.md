# Loadbar 1.3.1

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

CPU temperature availability details now say **“CPU temperature is not available”** instead
of referring to an ASUS interface. This also applies to the initial reading before collection.
Native error codes and metric statuses are preserved.

This patch changes wording only. Temperature-provider coverage, sampling, settings and
rendering behavior are unchanged. Additional CPU-temperature integrations remain future work.

## Upgrade

Exit through **Exit Loadbar** in Settings or the tray/bar menu, replace `Loadbar.exe`, and
launch it. Existing settings are preserved.

## Validation status

All four CTest suites pass in Debug, Release and ASan. Formatting, the full clang-tidy scan
and MSVC analysis pass. Release imports/security flags and the single-executable ZIP were
verified. Details are in [testing](https://github.com/Vorta/Loadbar/blob/v1.3.1/docs/testing.md)
and [packaging](https://github.com/Vorta/Loadbar/blob/v1.3.1/docs/packaging.md).

The owner requested this wording-only patch release with the previously disclosed validation
gaps remaining: controlled performance/soak, the full interactive Windows matrix, hardware
accuracy and clean-machine standalone execution. Publication does not establish that those
gates passed. No new performance measurement is claimed for this patch.
