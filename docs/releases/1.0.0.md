# Loadbar 1.0.0

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

Initial open-source version of Loadbar, a native system-monitoring AppBar for one selected
monitor. It reserves work area, supports all four edges, and provides tray Settings/Exit.

- Physical-core CPU rectangles with logical-processor details.
- Physical RAM percentage and used/total GB.
- Every physical disk's active time, read and write throughput.
- Selected GPU's 3D, video-decode and supported adapter-memory metrics.
- Selected interface's upload/download rates.
- Per-direction session-peak rate scales, last-valid reading continuity, DPI/text scaling,
  high-contrast rendering, and persisted settings.

## Files

- `Loadbar.exe`: standalone Windows x64 executable.
- `Loadbar-1.0.0-windows-x64.zip`: the same executable, compressed; no companion runtime files.
- `SHA256SUMS.txt`: checksums for both downloads.
- Source archives are provided by GitHub from the release tag.

Run the executable, use its notification icon for Settings, and exit through the tray/bar
menu or Settings to release the reservation. Settings are per-user, under
`HKCU\Software\Loadbar`. No installation or launch-at-sign-in registration is performed.

## Validation status

Build/test/analysis and import evidence are recorded in
[testing](https://github.com/Vorta/Loadbar/blob/v1.0.0/docs/testing.md) and
[packaging](https://github.com/Vorta/Loadbar/blob/v1.0.0/docs/packaging.md).
Interactive Shell/fullscreen/multi-monitor behavior, physical-hardware accuracy, sustained
performance/soak, and clean-machine standalone packaging are not yet release-qualified.
No performance numbers or clean-machine guarantees are claimed. Unsupported counters and
unverified GPU memory scopes remain explicitly unavailable in the application.

The README animation uses synthetic readings in the actual renderer. It is not hardware
validation, a desktop recording or a measurement of application overhead.
