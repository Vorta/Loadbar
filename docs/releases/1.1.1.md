# Loadbar 1.1.1

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

This patch fixes CPU thread visibility and spacing, and reduces allocation and rendering costs.

## Changes

- **Show every logical processor.** A four-core/eight-thread CPU now displays eight separate
  tiles with independent utilization colors, retained readings and hover details. Sibling
  threads remain adjacent, and details identify their physical core.
- **Remove unused CPU space.** CPU width follows its tile grid and bar thickness. RAM and
  the other visible device meters share the remaining width equally.
- **Reuse GPU aggregation storage** instead of allocating temporary map/set nodes each sample,
  while retaining adapter, engine, interval and duplicate-counter validation.
- **Release hidden-provider scratch buffers** when GPU or all disks are hidden, preserving
  device preferences, last-valid observations and session peaks.
- **Bound glow rendering memory and resolution** at large bar sizes while retaining cached
  drawing and resource-loss recovery.
- **Back off failed network reads** instead of retrying every sample; selection and recovery
  events reset the retry state.
- Refresh README visuals to use the current renderer.

## Downloads and upgrade

- `Loadbar.exe`: Windows x64 executable.
- `Loadbar-1.1.1-windows-x64.zip`: the same executable, compressed.
- `SHA256SUMS.txt`: checksums for both downloads.

Exit the running version through its tray/bar menu or Settings, replace `Loadbar.exe`,
and launch the new executable. Existing settings remain under `HKCU\Software\Loadbar`.
No installer, service or launch-at-sign-in registration is added.

## Validation status

Debug, Release, RelWithDebInfo and ASan passed all four CTest suites. Formatting and MSVC
analysis passed. The full clang-tidy run found one conversion warning in a test assertion;
it was fixed and the affected file passed a rerun. Independent performance-focused and
adversarial reviews were followed by fixes and two consecutive clean independent reviews.
The CPU-spacing follow-up also received two clean independent reviews and final rechecks.

Release imports contain only Windows components, with no VC++ runtime DLL dependency.
The release ZIP contains only the tested executable. Synthetic allocation and rendering
probes support the targeted optimizations; they are not measurements of final process overhead.

Live Shell/fullscreen/multi-monitor behavior, hardware accuracy and hotplug, controlled
performance measurements of this version, one-hour soak, and clean-machine standalone
packaging remain pending. Publication does not establish that these release gates have passed.
