# Loadbar 1.3.0

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

- **Always show readout**, enabled by default for new and migrated settings, places two-line
  numeric summaries beside every graphic. All logical-processor tiles and device meters remain.
- CPU total/P/E averages, RAM percentage/capacity, GPU 3D/memory/decode, drive active/read/write,
  and network download/upload use compact, color-matched Geist Mono text.
- Vertical readouts follow the edge's reading direction, with upright icons and temperatures.
  Constrained edges reflow through the existing readable-minimum placement policy.
- Disable the setting to restore the original graphics layout and saved hover behavior.
  Tooltips remain independently controlled. Changing readouts does not restart collection.
- Tighter spacing and aligned Geist Mono typography keep the readouts compact. README
  animations compare both modes with temperatures and square CPU tiles at the same scale.

## Upgrade

Exit through **Exit Loadbar** or the tray/bar menu, replace `Loadbar.exe`, and launch it.
Settings migrate automatically; **Always show readout** starts enabled. Uncheck it in
Settings and select Apply to keep the graphics-only presentation.

## Validation status

All four CTest suites pass in Debug, Release, RelWithDebInfo and ASan. Formatting, clang-tidy
and MSVC analysis pass. Release imports and security flags were inspected; the ZIP contains
only the tested executable. See [testing](https://github.com/Vorta/Loadbar/blob/v1.3.0/docs/testing.md)
and [packaging](https://github.com/Vorta/Loadbar/blob/v1.3.0/docs/packaging.md).

An independent performance review found no actionable issue in caches, collection, handoff
or resource lifetime. A ten-minute observation of the final executable at the existing 250 ms
cadence, with readouts off, measured 12.51 ms/s CPU, 67.09 MiB median private bytes and
72.88 MiB median working set. CPU/private memory exceeded the provisional targets in that
configuration; resource counts were stable over the interval. Details and limits are in
[performance](https://github.com/Vorta/Loadbar/blob/v1.3.0/docs/performance.md).

The owner approved the implementation and requested publication after the remaining validation
gaps were disclosed. Controlled 1-Hz horizontal/vertical performance, GPU/DWM attribution,
the one-hour soak, the full interactive Windows matrix, hardware accuracy and clean-machine
standalone execution remain pending. Publication does not establish that these gates passed.
