# Loadbar 1.1.5

Author: **Vorta** · License: **MIT** · Platform: **Windows 11 x64**

This update makes popup tooltips more compact and gives them an independent setting.

## Changes

- **Compact quantities.** RAM/GPU memory uses MB or GB; disk/network rates and session peaks
  use MB/s or GB/s, with one decimal place. Units follow the Windows-style binary convention,
  identified in the tooltip. Tiny positive values show `<0.1 MB` or `<0.1 MB/s`; zero stays zero.
  Redundant raw-byte capacity lines are removed. Inline and Settings readings keep their formats.
- **Independent tooltip control.** The new **Show tooltips** checkbox sits below **Show info
  on hover**. Use either, both or neither: hover info controls numbers on the bar, while the new
  setting controls its popup. The tray tooltip remains available. Changes apply without restarting collection.
- **Compatible settings migration.** Existing installations inherit the tooltip choice from
  their old hover setting; new installations enable both. The choices then persist independently.

## Downloads and upgrade

- `Loadbar.exe`: Windows x64 executable.
- `Loadbar-1.1.5-windows-x64.zip`: the same executable, compressed.
- `SHA256SUMS.txt`: checksums for both downloads.

Exit the running version through **Exit Loadbar** or its tray/bar menu, replace `Loadbar.exe`,
and launch the new executable. Existing settings migrate automatically. No installer is required.

## Validation status

Debug, Release, RelWithDebInfo and ASan builds passed all four CTest suites each. Formatting,
clang-tidy and MSVC analysis checks completed, with findings fixed and affected checks rerun.
Tests cover compact formatting, settings migration, independent inline/popup modes, hidden
native tooltip activation, checkbox backgrounds and keyboard/layout behavior. The owner
reports that the changes look good and requested publication.

Release imports contain only Windows components, and the ZIP contains only the tested executable.
The full interactive Shell/fullscreen/multi-monitor matrix, hardware accuracy, controlled
performance measurements, one-hour soak and clean-machine standalone execution remain pending.
